# Community conduct

Worldfolk contributors should be able to collaborate respectfully, regardless of experience, nationality, ethnicity, religion, gender, disability or background.

Be constructive and specific in feedback. Respect Ghanaian places, communities and cultural practices. Critique the work without personal attacks. Credit other people's work and respect privacy and asset rights.

Harassment, discriminatory abuse, threats, impersonation, sexual harassment, doxxing and publishing private player/contributor information are unacceptable in project spaces. Do not use reviews or issues to advertise unrelated services or pressure others for personal contact.

Maintainers may edit/remove harmful content, lock discussions, reject contributions or restrict participation proportionately. Decisions should consider context and give a clear reason where doing so is safe. Maintainers are also expected to follow this policy.

Report concerns to a repository maintainer using an available private channel; if none is published, request one in a minimal issue without naming affected people or posting sensitive evidence publicly. The project does not currently publish a dedicated conduct email or promise a response time. For security disclosures follow [SECURITY.md](SECURITY.md).
